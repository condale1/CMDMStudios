# CMDM Studios Website

This is a simple static website for CMDM Studios, an independent game development company.

## Files
- `index.html`: The main homepage.
- `style.css`: Basic styling for the site.

## Preview
To preview the site locally:
1. Navigate to the project directory.
2. Run `python3 -m http.server 8000`
3. Open `http://localhost:8000` in your browser.

## Hosting
To use this as your business website for Stripe, you need to host it online. Options include:
- GitHub Pages
- Netlify
- Vercel
- AWS S3 + CloudFront

Upload the files to your chosen hosting platform and get a domain (e.g., cmdmstudios.com).

## Customization
Feel free to add images, more pages, or integrate Stripe payments if needed.
